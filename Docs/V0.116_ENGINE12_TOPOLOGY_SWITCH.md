# ZETAGOLD — V0.116 Engine 1/2 Topology Switch

## Status

The main execution unit `EA/EAGOLD.mq4` has been switched to the v0.116 Engine 1 / Engine 2 composition topology on branch `refactor/v0.116-engine12-parity`.

Commit: `79c777a0903f5d5337e3d16d642cce5ee687db99`

## Main topology

`EA/EAGOLD.mq4` now loads:

- Core: Config, Action Contract, Orders, R12, Excursion Tracker, Counterfactual Path Telemetry, Adaptive Profit Guard, Trading Guards, Execution.
- `EAGOLD_R10_Reconciliation.mqh` as cross-cutting reconciliation infrastructure.
- `EAGOLD_Engine1_LifecycleRecovery_v0116.mqh` as the Lifecycle & Recovery boundary.
- `EAGOLD_Engine2_Exposure_v0116.mqh` as the Exposure Management boundary.
- R13 Satellite as a specialized external economic satellite.
- Persistence and UI as external infrastructure.

The old R9/R10/Recovery/Lifecycle/R1 compatibility shims remain on disk and are consumed transitively by the Engine composition layers. They are intentionally not deleted in this step.

## Behavioral constraint

This change is structural. No trading-rule redesign is intended. The v0.116 `OnTick()` ordering is retained.

## Validation gate

MetaEditor compilation has **not** been claimed or performed through this GitHub operation. The next gate is a static duplicate-symbol/include dependency audit followed by actual MetaEditor compilation and runtime/backtest validation.

No compatibility shim should be removed until that validation passes.
